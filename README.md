# 桌面折页

桌面折页是 Windows 10/11 的本地应用文件夹。首次运行时，桌面右上角会出现「常用」。单击文件夹展开，双击里面的 App 启动。点面板外、点 × 或按 Esc 可以收起。

- 从桌面拖快捷方式到文件夹图标或展开后的面板。也可以点击面板上的 ＋，选择一个或多个快捷方式或 EXE。
- 直接拖入桌面上的普通文件夹时，确认窗口会列出原位置和 D:\desktop 下的目标位置。确认后，折页会创建指向目标的快捷方式，并用 Windows 移动文件夹。取消确认不会收纳或移动。同名目标会使用带编号的新目录。移出折页或退出还原时，桌面收到的是快捷方式，实际文件夹保存在 D:\desktop。拖入其他位置的文件夹或桌面上的目录链接时，只添加快捷方式。
- 在面板里把 App 拖到另一个图标左侧或右侧，蓝线表示插入位置。顺序会自动保存。
- 拖动桌面上折叠的文件夹图标来调整位置。右键图标可以新建、重命名或移除空文件夹。在新建窗口里每行填一个名称，一次就能创建多个文件夹。
- 把折叠的文件夹拖到屏幕外沿再松手，它会收起，只留一条显示名称的标签。鼠标移到标签上会显示文件夹，单击可展开。把标签从边缘拖回桌面即可取消贴边。
- 贴边标签会根据实际显示在边缘的画面切换深浅。Wallpaper Engine（小红车）的壁纸正在显示时，标签会以它的画面为准。折页仅在内存中读取标签区域的小块屏幕像素，按两侧亮度切换颜色，不保存图像。
- 要把 App 移出分组，把它拖到桌面空白处，或右键点击「移回桌面」。也可以把它拖进另一个文件夹。
- 右键桌面文件夹或通知区域的「桌面折页」图标，再点「设置」，可以分别调整桌面图标和展开背景的不透明度，选择面板颜色或本地图片。选图后点「裁剪 / 旋转」。可拖出选区、移动选区、拖四角缩放或左右旋转 90 度。点「应用」后保存设置。面板用选区铺满背景，原图片保留。移动或删除原图后会显示设置的底色。
- 右键某个折页图标，点「展开背景」，即可单独设置这一组的背景色、图片、裁剪和展开背景不透明度。点「使用全局背景」可恢复为通用设置。
- 在全局「设置」勾选「自定义任务栏背景透明度」并拖动滑块，可以实时预览任务栏背景。图标和时钟保留正常不透明度。点「保存」保留设置，取消则回到进入设置前的效果。关闭开关、调到 100% 或正常退出折页后，任务栏恢复系统外观。
- 在「设置」勾选「开机自启动」并保存，当前 Windows 用户登录时就会打开桌面折页。设置之前可先把 EXE 放在固定位置。如果以后移动了 EXE，手动运行新位置下的 EXE 一次即可更新启动快捷方式。

加入个人或公共桌面上的快捷方式时，程序会收纳原图标。公共快捷方式收纳后会从公共桌面移出，还原时放到当前用户的个人桌面，并尽量使用原坐标。如果 Windows 拒绝移走原快捷方式，移出分组会使用留在桌面的原图标。选择桌面上的 EXE 会保留原程序，移出分组时也不会另外建一枚快捷方式。壁纸、应用和应用数据照常使用。

文件夹、顺序、位置、外观和收纳的快捷方式保存在 %LOCALAPPDATA%\桌面折页。升级时先从通知区域退出旧版，再运行新版本。新版会识别旧分组中与公共桌面文件同名且内容相同的快捷方式，并尝试收起原图标。

桌面上的白色细线「桌面折页」图标用于启动程序。每次运行新版时，启动图标会指向本次运行的 EXE。

「退出时把收纳的快捷方式放回桌面」默认开启。用通知区域里的「退出桌面折页」退出时，程序会放回快捷方式，等 Explorer 登记图标，再批量还原并核对落点。再次打开会重新收纳这些快捷方式，保留已经记录的原坐标、分组和顺序。退出期间被改名或修改过的快捷方式会留在桌面。原位被占用、Windows 自动排列或旧条目没有记录位置时，Windows 会安排落点。最近一次还原异常可在 %LOCALAPPDATA%\桌面折页\退出还原记录.txt 查看。旧版收纳条目统一按可恢复的快捷方式处理，新版从桌面外添加的快捷方式和 EXE 仅保存在分组内。

## 从源码构建

在 Windows PowerShell 中运行 .\Build.ps1，生成 DesktopFolders.exe。使用 Windows 自带的 .NET Framework 4.8 编译工具和 WPF，无需 NuGet 包。

文件夹图标是独立的原生窗口。程序用 Windows 窗口顺序把图标放在 Explorer 桌面图标层上方、普通应用窗口下方。
